# Open Product and Architecture Decisions

This document tracks significant unresolved decisions for the Dental Record System.

It is not a source of approved requirements.

Approved product decisions must be moved into `PRD.md`.

Approved architecture decisions must be recorded under `docs/architecture/decisions/`.

## Decision Format

Each open decision should contain:

- ID
- Topic
- Question
- Why it matters
- Current options
- Recommended direction, if one exists
- Blocked work, if any
- Status
