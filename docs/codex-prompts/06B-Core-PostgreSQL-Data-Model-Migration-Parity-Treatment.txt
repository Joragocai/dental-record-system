DATES / TIMESTAMPS

Use:

(default Asia/Manila) where calendar-boundary behavior matters.

Do not make date behavior depend accidentally on the host machine timezone.

- avoid floating-point storage
- preserve exact V1 semantics
- do not implement Finance ledger behavior in this batch

Treatment merely for convenience. Document the dependency.
