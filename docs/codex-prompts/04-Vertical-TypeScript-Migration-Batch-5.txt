TYPE-SAFETY RULES

For migrated files:
- use strict TypeScript;
- use `.ts` for non-React modules;
- use `.tsx` for React JSX modules;
- preserve current runtime behavior;
- add minimum accurate types;
- use domain-specific interfaces/types where they clarify actual contracts;
- preserve legacy nullable/optional values accurately;
- avoid broad `any`;
- use `unknown` only when values are genuinely untrusted and narrow them;
- no `@ts-ignore`;
- no `@ts-nocheck`;
- no weakening compiler settings;
- no unsafe assertions merely to silence TypeScript;
- do not invent enums/literal unions unless the current contract proves the values are exhaustive.

Do not treat TypeScript as runtime validation.
